# نظام شركة المستثمرين للتطوير الصناعي والعقاري

نسخة أولية قابلة للتشغيل على خادم، وليست نظام ERP محاسبيًا مكتملًا أو منشورًا بالفعل.

## الوحدات
المستثمرون، قطع الأراضي، عقود المستثمرين، الأقساط، التحصيلات، المقاولون، المشروعات، عقود المقاولات، المستخلصات، المصروفات، لوحة الإدارة والتقارير.

## التشغيل على خادم Linux مع Docker
1. انسخ `.env.example` إلى `.env` وغير كلمات المرور والمفاتيح والنطاق.
2. جهّز Reverse Proxy (مثل Caddy أو Nginx) مع شهادة HTTPS، لتمرير الطلبات إلى `127.0.0.1:8000`.
3. نفّذ:
   ```bash
   docker compose up -d --build
   docker compose exec web python manage.py migrate
   docker compose exec web python manage.py createsuperuser
   ```
4. افتح `https://erp.example.com/login/` بعد ضبط DNS وHTTPS.
5. أنشئ مجموعات وصلاحيات من لوحة `/admin/`، ولا تمنح `is_superuser` إلا لمسؤول النظام.

## ملاحظات أمنية وتشغيلية
- لا تستخدم الإعدادات النموذجية أو كلمات المرور المذكورة في `.env.example` في الإنتاج.
- فعّل نسخًا احتياطية مشفرة لقاعدة PostgreSQL واختبر استعادتها دوريًا.
- لا تنشر المنفذ 8000 مباشرة على الإنترنت؛ استخدم HTTPS أمامه.
- الأدوار تعتمد على Django permissions؛ صفحات العرض محمية بالصلاحيات، ولوحة الإدارة تضبط صلاحيات الإضافة والتعديل والحذف.
- سجلات التدقيق الحالية مجرد جدول تمهيدي ولم يتم بعد توصيله تلقائيًا بكل العمليات.
- لا يوجد حاليًا دفتر أستاذ مزدوج القيد، أو ترحيل مستخلصات، أو اعتماد متعدد المراحل فعلي، أو إدارة مرفقات، أو نسخ احتياطي آلي، أو مصادقة متعددة العوامل.
- يلزم اختبار وظيفي وأمني ومراجعة محاسبية وقانونية قبل إدخال بيانات الشركة الحقيقية.
